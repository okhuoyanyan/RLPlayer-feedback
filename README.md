# RLPlayer 反馈与问题追踪 / Feedback

[官网 Website](https://rlplayer.rainlain.com) · [下载 Download](https://rlplayer.rainlain.com/download.html) · [使用说明 Manual](https://rlplayer.rainlain.com/manual.html) · [技术白皮书 White paper](https://rlplayer.rainlain.com/features.html)

这个仓库用于收集 **RLPlayer（Windows 正式发布版）** 的使用问题与改进建议。
This repository collects bug reports and suggestions for **RLPlayer (Windows release)**.

## 怎么提 / How to report

1. **软件内一键反馈**（推荐）：设置 → 帮助 → 一键反馈。会一并提交诊断包（日志、设备信息、脱敏后的配置）。
2. **在这里新建 Issue**：请附上版本号、Windows 版本、音频设备型号、复现步骤；有日志更好。

## 请务必包含 / Please include

- 版本号（设置 → 关于与更新 可见）
- Windows 版本与 CPU / GPU 型号
- 音频输出方式（WASAPI 独占 / 共享 / ASIO / UPnP）
- 复现步骤与期望结果
- 相关日志或截图

## 说明 / Notes

- 反馈不构成修复承诺；处理进展会直接在本仓库的 Issue 中更新。
- 本项目为 GPL-3.0-or-later 开源项目，问题定位与修复节奏由维护者安排。
- macOS 分支由独立协作者维护，请勿在此提交 macOS 问题。
